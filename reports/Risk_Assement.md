# Risk Assessment & Mitigation

| Risk ID | Risk Description | Likelihood | Impact | Mitigation Strategy |
|---------|------------------|------------|--------|---------------------|
| R1 | Requirements unclear/ambiguous | Medium | High | Weekly stakeholder review, use AI to check ambiguity |
| R2 | Team member unavailable | Medium | Medium | Assign backup roles, keep tasks small, WhatsApp updates |
| R3 | Delay in UML diagrams | Low | Medium | Use diagrams.net templates, start early |
| R4 | GitHub merge conflicts / lost work | Medium | Low | Commit frequently, pull before push, use single main branch |
| R5 | Prototype tool learning curve | Low | Medium | Use Figma tutorials, use simple wireframes |
| R6 | Scope creep (adding extra features) | Medium | High | Stick to assignment sheet, define In/Out of scope clearly |
