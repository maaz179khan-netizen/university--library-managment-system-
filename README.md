# University Library Management System - SE Project

## Case Scenario
A university library currently manages book borrowing, returns, student membership, and overdue books through manual records or an outdated system. The university wants a new Library Management System (LMS) to manage books, members, borrowing, returns, reservations, and overdue notifications.

## 1. Project Scope
**In Scope:**
- Book catalog management (add, update, delete, search)
- Member management (Student, Faculty, Librarian)
- Borrowing and returning with due dates
- Reservation system for unavailable books
- Overdue tracking and email notifications
- Dashboard and reports

**Out of Scope:**
- Full coding implementation (not required as per assignment)
- Payment integration
- ERP integration

## 2. Project Objectives
1. Analyze manual system problems and propose automated solution.
2. Specify functional and non-functional requirements.
3. Model system using UML diagrams.
4. Design UI prototype.
5. Maintain project using professional tools Git & GitHub.

## 3. Assumptions
- Max 10,000 books, 2,000 members.
- Each member can borrow max 5 books for 14 days.
- 3 roles: Librarian (Admin), Student, Faculty.
- Internet available in library.
- Librarian has basic computer knowledge.

## 4. Constraints
- Must complete in 4 weeks.
- Team of 2-3 members.
- Only SE artifacts required, no full code.
- Must use GitHub for version control.
