# Stakeholder Analysis - University Library Management System

### 1. Identified Stakeholders (4 Minimum)

1.  **Student:** Primary borrower, searches books, borrows/returns, checks due dates.
2.  **Faculty Member:** Research-oriented borrowing, reserves books, extended loan.
3.  **Librarian:** Day-to-day operations - issue, return, fine management, inventory.
4.  **Library Administrator (Admin):** System management, user management, reports, settings.
5.  **IT Support Staff (Additional):** System maintenance, backup, security.

### 2. Stakeholder-Needs Table

| Stakeholder | Role | Key Needs / Expectations | Priority |
| :--- | :--- | :--- | :--- |
| **Student** | Borrower | Search by title/author/ISBN, Check availability, View my borrowed books, Get overdue notification, Renew online | High |
| **Faculty Member** | Research Borrower | Advanced search, Reserve book, Longer loan period (30 days), Access to research papers section | High |
| **Librarian** | Operator | Add/update/delete books, Issue & Return in <2 min, Calculate fine automatically, View defaulter list, Generate daily report | High |
| **Library Admin** | Manager | Add/remove librarians, View all reports/analytics, Manage categories & fine rules, Backup data, Audit log | High |
| **IT Support** | Maintainer | Secure login, Easy backup/restore, Low maintenance, System logs | Medium |
