# UI Prototype

This folder contains UI/UX designs for University Library Management System.

## Prototype Screens Planned
1. Login Page (Librarian / Student / Faculty)
2. Dashboard - Book statistics, overdue alerts
3. Book Catalog - Search, filter, view details
4. Borrow Book - Select member and book
5. Return Book - Calculate fine if overdue
6. Member Management - Add / Edit members
7. Reservation Management
8. Reports Page
